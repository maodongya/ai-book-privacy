隐私政策

AIBook 在你这台 Mac 上读书。原文、选中文字、追问，以及语音操作听写成的文字，只会在你点讲解、翻译、发送或松开语音键时离开本机。

接收方是你在 book 设置里选中的那一家，发送按钮和菜单上方会写明公司名和主机名。各家用你自己的 API Key，Key 只存在本机。

麦克风只在你按住语音键时打开，用来把口令听成文字。系统能在本机识别时，音频不上传。听出的文字若要执行讲解或翻译，会按上面的接收方发送。

AIBook 需要麦克风，把你说的操作转成文字。

AIBook 需要语音识别，把你说的操作转成可执行的功能。

书籍文件、API Key 和设置写在本机的 Application Support 与偏好设置里。AIBook 不用这些内容做跨 App 跟踪。

Privacy Policy

AIBook reads on this Mac. Source text, selections, follow-up questions, and words heard by voice control leave the Mac only when you explain, translate, send, or release the voice key.

The recipient is the provider you chose in Book Settings. The company and host are written above the send button and in the menus. Each provider uses your own API key, stored only on this Mac.

The microphone turns on only while you hold the voice key, to turn a command into text. When the system recognizes speech on this Mac, the audio is not uploaded. If the recognized words run an explanation or translation, they go to the recipient above.

AIBook needs the microphone to turn what you say into text.

AIBook needs speech recognition to turn what you say into an action.

Books, API keys, and settings stay in Application Support and preferences on this Mac. AIBook does not use them to track you across apps.

プライバシー

AIBook はこの Mac で読書します。原文、選択、追問、音声操作で文字になった内容は、解説・翻訳・送信、または音声キーを離したときだけ外に出ます。

受け取り先は book 設定で選んだ提供者です。会社名とホスト名は送信ボタンとメニューの上に出ます。API Key は各社のもので、この Mac にだけ保存します。

マイクは音声キーを押している間だけ開き、命令を文字にします。システムがこの Mac で認識できるとき、音声は送りません。認識した文字で解説や翻訳を実行するときは、上の受け取り先へ送ります。

AIBook は、話した操作を文字にするためにマイクを使います。

AIBook は、話した操作を実行できる機能にするために音声認識を使います。

書籍、API Key、設定はこの Mac の Application Support と環境設定にあります。AIBook はこれで他の App をまたいで追跡しません。

Datenschutz

AIBook liest auf diesem Mac. Original, Auswahl, Nachfragen und erkannter Sprachtext verlassen den Mac nur beim Erklären, Übersetzen, Senden oder Loslassen der Sprachtaste.

Empfänger ist der Anbieter aus den Book-Einstellungen. Firma und Host stehen über der Senden-Taste und in den Menüs. Der API-Key jeder Firma bleibt nur auf diesem Mac.

Das Mikrofon ist nur bei gehaltener Sprachtaste an und macht aus dem Befehl Text. Erkennt das System lokal, wird Audio nicht hochgeladen. Erkannter Text für Erklärung oder Übersetzung geht an den Empfänger oben.

AIBook benötigt das Mikrofon, um Gesagtes in Text zu verwandeln.

AIBook benötigt die Spracherkennung, um Gesagtes in eine Aktion zu verwandeln.

Bücher, API-Keys und Einstellungen bleiben in Application Support und den Einstellungen auf diesem Mac. AIBook verfolgt dich damit nicht über Apps hinweg.

Le destinataire est le fournisseur choisi dans les réglages book. La société et l’hôte sont indiqués au-dessus du bouton d’envoi et dans les menus. La clé API reste seulement sur ce Mac.

AIBook a besoin de la reconnaissance vocale pour transformer ce que vous dites en action.

Il destinatario è il fornitore scelto nelle impostazioni book. Società e host compaiono sopra il pulsante di invio e nei menu. La chiave API resta solo su questo Mac.

AIBook usa il microfono per trasformare ciò che dici in testo.

AIBook usa il riconoscimento vocale per trasformare ciò che dici in un’azione.

Privata

AIBook in hoc Mac legit. Textus, selectum, quaestiones et verba audita Mac relinquunt tantum cum explicas, transfers, mittis aut clavem vocis solvis.

Accipiens est praebitor electus in configuratione book. Societas et hospes supra mittendi bullam et in menus scribuntur. Clavis API tantum in hoc Mac manet.

Microphonum tantum dum clavem vocis tenes apertum est, ut mandatum in textum vertat. Si systema in hoc Mac agnoscit, sonus non mittitur. Verba agnita quae explicationem aut translationem incipiunt ad accipientem supra eunt.

AIBook microphono eget ut dicta in textum vertat.

AIBook recognitione vocis eget ut dicta in actionem vertat.

Libri, claves API et configurationes in Application Support et praeferentiis huius Mac manent. AIBook eis non utitur ut te per applicationes sequatur.
